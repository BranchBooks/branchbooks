# Security

Please don't report a security problem in a public issue: installed copies of BranchBooks update
themselves, and people's books and git tokens are at stake.

Report it privately as a [confidential issue](https://gitlab.com/branchbooks/branchbooks/-/issues/new?issue[confidential]=true):
only you and the maintainers can see it. Say what you found, how to reproduce it, and which version
you tested. Only the latest release is supported.

Never include real financial data, or a real token, in a report.
